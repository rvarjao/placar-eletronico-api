O Projeto Interclasse convida estudantes do 2º ano de Desenvolvimento de Sistemas a transformar necessidades reais de um campeonato escolar em produtos digitais.

Cada equipe escolhe uma modalidade e desenvolve uma solução para o dia a dia do torneio: placar, chaveamento, classificação, agenda ou estatísticas.

01

Planejar

Identificar o problema, definir funcionalidades e desenhar a experiência.

02

Construir

Programar interfaces e regras de negócio, usando Git e GitHub no processo.

03

Apresentar

Demonstrar a solução, explicar as escolhas e compartilhar a evolução do projeto.

Caminho do projeto

Da ideia à quadra.

  1. 01

    Planejamento

    Objetivos, funcionalidades, tecnologias, telas e organização da equipe.

  2. 02

    Protótipo funcional

    Primeira versão navegável, com as funcionalidades principais já em desenvolvimento.

  3. 03

    Evolução

    Aprimoramentos, testes, integração das funcionalidades e evidências do funcionamento.

  4. 04

    Apresentação final

    Sistema concluído, demonstração prática e conversa sobre o que foi aprendido.
