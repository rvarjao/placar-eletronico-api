Instruções para a IA

Referência técnica

Contrato da API publicada.

URL base: https://rvarjao.pythonanywhere.com/api

Autenticação: Authorization: Bearer TOKEN_DO_GRUPO. Para enviar JSON, use Content-Type: application/json.

MétodoRota relativa à URL baseFinalidadeSucesso
GET/placaresListar placares200
POST/placares/criarCriar placar201
GET/placares/{id}Consultar placar200
PATCH/placares/{id}Alterar campos do placar200

Criação (POST)

{
  "nome_equipe_a": "Equipe A",
  "nome_equipe_b": "Equipe B",
  "modalidade": "volei"
}

Guarde o ID retornado. A API inicia pontos e tempo em zero e status em aguardando.

Atualização (PATCH)

{
  "pontos_a": 21,
  "pontos_b": 18,
  "status": "em_andamento",
  "tempo_partida": 600
}

Envie apenas os campos alterados. Status: aguardando, em_andamento, encerrado. Pontos e tempo em segundos são inteiros não negativos. Sets, faltas e outras estatísticas permanecem no seu sistema.

Erros comuns: 400 (dados inválidos), 401 (token inválido), 403 (operação não autorizada), 404 (placar inexistente), 503 (dependência indisponível). Confira o código de referência da API publicada.

Exemplos práticos

Escolha sua tecnologia.

Projetos hospedados no GitHub Pages: um token no navegador não é secreto. A API aceita chamadas diretas do navegador de qualquer origem, sem cadastro prévio. O operador informa o token em tempo de execução; nunca o publique no código. Para acesso automático sem operador, use um backend autenticado com segredo no servidor.

JavaScript puro · GitHub Pages

Você pode testar diretamente do GitHub Pages ou de um servidor local, como http://localhost:5500.

// JavaScript no navegador — envie o token do grupo.
// O operador informa o token na interface; não grave no código ou localStorage.
const BASE = 'https://rvarjao.pythonanywhere.com/api';
let token = '';

function configurarToken(valor) {
  token = valor.trim(); // apenas em memória; desaparece ao recarregar
}

async function api(caminho, metodo = 'GET', dados) {
  if (!token) throw new Error('Informe o token do grupo');
  const resposta = await fetch(BASE + caminho, {
    method: metodo,
    headers: {
      Authorization: 'Bearer ' + token,
      ...(dados ? {'Content-Type': 'application/json'} : {})
    },
    ...(dados ? {body: JSON.stringify(dados)} : {}),
    signal: AbortSignal.timeout(15000)
  });
  if (!resposta.ok) {
    const erro = await resposta.json().catch(() => ({}));
    throw new Error(erro.erro || 'API: HTTP ' + resposta.status);
  }
  return resposta.json();
}

// Vincule a um campo type="password" da sua interface.
// configurarToken(campoToken.value); campoToken.value = '';

// No botão de criação (apenas uma vez por partida):
async function criarPartida() {
  const placar = await api('/placares/criar', 'POST', {
    nome_equipe_a: 'Meu grupo — Equipe A',
    nome_equipe_b: 'Meu grupo — Equipe B',
    modalidade: 'volei'
  });
  return placar.id; // persista este ID, não o token
}

// Use o ID já associado à partida.
async function atualizarPartida(id) {
  return api('/placares/' + id, 'PATCH', {
    pontos_a: 1, status: 'em_andamento'
  });
}

async function consultarPartida(id) {
  return api('/placares/' + id);
}

// Ao sair da área de operação:
function desconectar() { token = ''; }

O navegador envia Origin e executa automaticamente o preflight OPTIONS. Não use mode: no-cors. O token continua necessário e não deve ser compartilhado com visitantes.

JavaScript · Node.js

// Node.js 18+ (servidor). Nunca coloque o token no frontend público.
const base = 'https://rvarjao.pythonanywhere.com/api';
const token = process.env.INTERCLASSE_TOKEN;
if (!token) throw new Error('Configure INTERCLASSE_TOKEN no servidor');

async function api(caminho, metodo = 'GET', dados) {
  const resposta = await fetch(base + caminho, {
    method: metodo,
    headers: {
      Authorization: 'Bearer ' + token,
      ...(dados ? {'Content-Type': 'application/json'} : {})
    },
    ...(dados ? {body: JSON.stringify(dados)} : {}),
    signal: AbortSignal.timeout(15000)
  });
  if (!resposta.ok) throw new Error('API: HTTP ' + resposta.status);
  return resposta.json();
}

// Execute a criação apenas uma vez por partida; persista o id retornado.
async function criarPartida() {
  const placar = await api('/placares/criar', 'POST', {
    nome_equipe_a: 'Meu grupo — Equipe A',
    nome_equipe_b: 'Meu grupo — Equipe B',
    modalidade: 'volei'
  });
  return placar.id;
}

// Use o ID que o seu sistema já armazenou.
async function atualizarPartida(id) {
  await api('/placares/' + id, 'PATCH', {
    pontos_a: 1, status: 'em_andamento'
  });
  return api('/placares/' + id);
}

Python · requests

# Python (servidor). Instale requests: pip install requests
import os
import requests

BASE = "https://rvarjao.pythonanywhere.com/api"
TOKEN = os.environ["INTERCLASSE_TOKEN"]

def api(caminho, metodo="GET", dados=None):
    resposta = requests.request(
        metodo, BASE + caminho,
        headers={"Authorization": f"Bearer {TOKEN}"},
        json=dados, timeout=15,
    )
    resposta.raise_for_status()
    return resposta.json()

# Crie somente uma vez por partida e persista o ID no seu sistema.
def criar_partida():
    placar = api("/placares/criar", "POST", {
        "nome_equipe_a": "Meu grupo — Equipe A",
        "nome_equipe_b": "Meu grupo — Equipe B",
        "modalidade": "volei",
    })
    return placar["id"]

# Use o ID já armazenado da sua própria partida.
def atualizar_partida(id_placar):
    api(f"/placares/{id_placar}", "PATCH", {
        "pontos_a": 1,
        "status": "em_andamento",
    })
    return api(f"/placares/{id_placar}")

Para os exemplos Node.js e Python, configure INTERCLASSE_TOKEN como variável de ambiente ou segredo do servidor. Os exemplos definem funções; adapte e chame-as nos eventos do seu projeto, armazenando o ID da criação. Não execute uma nova criação a cada atualização.
